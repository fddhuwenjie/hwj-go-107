# 接口契约

统一约定：

- 所有请求/响应均为 `application/json; charset=utf-8`。
- 时间字段为 Unix 秒（数字）。
- 错误统一为 `{"error":{"code":"...","message":"..."}}`，HTTP 状态码语义化：`400` 参数错误、`404` 不存在、`409` 冲突（乐观锁/状态约束/幂等约束外的业务冲突）、`422` 业务规则不满足、`500` 内部错误。
- 列表接口使用键集分页：请求 `?cursor=<上次返回的 next_cursor>&limit=<1..200，默认 50>`，响应 `{"items":[...],"next_cursor":"..."}`，`next_cursor` 为空表示没有更多。
- 写接口幂等：清点与交接接口携带 `idempotency_key`，重复提交返回首次创建的结果（HTTP 200，`"idempotent_replay": true`）。
- 可变实体更新须携带 `version` 进行乐观锁校验，冲突返回 `409 {"error":{"code":"conflict"}}`。

## 2. 藏品

### POST /api/v1/artifacts 登记藏品

请求：

```json
{"code":"WJ-0001","name":"宋刻本《史记》","category":"古籍","era":"宋","description":"...","level_id":1}
```

响应 `201`：藏品对象（`status=registered`）。

### GET /api/v1/artifacts 分页查询

支持 `status`、`storage_unit_id`、`cursor`、`limit`。

### GET /api/v1/artifacts/{id} 详情

### PATCH /api/v1/artifacts/{id} 修改基础信息

请求携带 `version`；仅允许修改 `name/category/era/description/note`；`frozen/out/on_loan/returned_pending` 状态拒绝修改。

### POST /api/v1/artifacts/{id}/assign-location 分配库位

```json
{"storage_unit_id":2,"version":3}
```

### POST /api/v1/artifacts/{id}/retire 注销

```json
{"reason":"修复复核确认为仿品","version":4}
```

仅 `registered/stored` 可注销；保留全部历史与审计。

### GET /api/v1/artifacts/{id}/snapshots 状态历史快照

### POST /api/v1/artifacts/{id}/attachments 登记附件

```json

```

### GET /api/v1/artifacts/{id}/attachments 附件列表

## 6. 异常与处置

### GET /api/v1/anomalies 分页查询（`status`、`storage_unit_id` 过滤）

### POST /api/v1/anomalies/{id}/isolate 隔离保护

```json
{"operator":"张三","action_type":"isolate","note":"转移至应急柜","version":1}
```

事务内：异常→`isolating`、处置记录创建、单元内在库藏品→`isolated`、快照与审计。

### POST /api/v1/anomalies/{id}/disposals 登记处置

```json
{"operator":"李四","action_type":"dehumidify","note":"除湿 4 小时"}
```

处置完成即进入 `reviewing`。

### POST /api/v1/disposals/{id}/review 处置复核

```json
{"reviewer":"王五","pass":true,"note":"复检合格"}
```

通过：异常→`closed`，单元内 `isolated` 藏品→`stored`；不通过：异常→`disposing`。

## 7. 借展

### POST /api/v1/loans 创建借展申请

```json
{"code":"LN-2026-001","borrower":"省博物馆","venue":"一层临展厅","purpose":"特展","start_at":1756000000,"end_at":1758000000,"artifact_ids":[1,2]}
```

### POST /api/v1/loans/{id}/submit 提交

### POST /api/v1/loans/{id}/cancel 撤销

### POST /api/v1/loans/{id}/reject 驳回

```json
{"reviewer":"赵六","reason":"展期冲突"}
```

### POST /api/v1/loans/{id}/approve 审批通过

```json
{"reviewer":"赵六"}
```

校验：藏品均处于 `stored`；所在库房无未关闭异常；库房在审批时刻前的前置窗口内采样连续合格。成功后冻结藏品状态、保存等级、包装清单与规则快照，藏品→`frozen`。

### POST /api/v1/loans/{id}/out-check 出库清点+首段交接（同一事务）

```json
{
  "idempotency_key":"out-LN-2026-001",
  "operator":"清点员甲",
  "items":[{"artifact_id":1,"present":true,"attachments":[{"attachment_id":10,"present":true}]}],
  "handover":{"from_person":"库管员A","to_person":"押运员B","handed_at":1756100000,"location":"库房发货区"}
}
```

约束：清点必须覆盖全部藏品与附件；无未关闭异常；幂等键去重。成功后借展→`in_transit`，藏品→`out`。

### POST /api/v1/loans/{id}/handovers 追加交接

```json
{"idempotency_key":"ho-2","from_person":"押运员B","to_person":"展馆接收员C","handed_at":1756200000,"location":"省博收货区"}
```

约束：`handed_at` 严格递增；`to_person` 不得与上一段接收方重复；`from_person` 必须等于上一段接收方。

### POST /api/v1/loans/{id}/transport-nodes 追加运输节点

```json
{"node_type":"transit","location":"南京中转仓","occurred_at":1756150000,"recorded_by":"押运员B"}
```

### POST /api/v1/loans/{id}/exhibition-confirm 展陈确认

```json
{"showcase_id":9,"confirmed_by":"展馆接收员C","note":"恒温恒湿展柜"}
```

校验展柜前置窗口连续合格且无未关闭异常；借展→`exhibiting`，藏品→`on_loan`。

### POST /api/v1/loans/{id}/in-check 归还清点

与出库清点同构（`direction=in`），成功后借展→`returned`，藏品→`returned_pending`。

### POST /api/v1/loans/{id}/return-acceptance 归还验收（与借展关闭同一事务）

```json
{"result":"pass","reviewer":"王五","note":"完好"}
```

`pass`：藏品→`stored`；`pass_with_notes`：藏品→`stored` 并记录意见；`rejected`：藏品→`isolated`。借展→`closed`。此后到达的迟到环境数据不得改变验收结论。

### GET /api/v1/loans 分页查询（`status` 过滤）

### GET /api/v1/loans/{id} 详情（含冻结快照、清点、交接、节点、确认、验收）

## 8. 专题查询

### GET /api/v1/queries/loans/upcoming-with-anomalies?days=7

查询 `days` 天内即将开始、但借展藏品所在库房仍有未关闭环境异常的借展单与藏品清单。

### GET /api/v1/queries/warehouses/risk-ranking

库房风险排序：未关闭异常按严重级别加权（轻微 1/严重 3/危急 5）加最近 24 小时越界采样数，降序返回。

### GET /api/v1/queries/sensors/consecutive-breaches?min=3

返回最近连续 `min` 次采样全部越界的传感器及连续次数。

### GET /api/v1/queries/loans/{id}/packaging-diff?direction=in

比对冻结包装清单与指定方向清点结果的差异（缺失/多余的藏品与附件）。

### GET /api/v1/queries/loans/overdue

逾期未归还借展单列表（`end_at < now` 且未关闭）。
