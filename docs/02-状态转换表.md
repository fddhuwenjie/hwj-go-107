# 状态转换表

## 1. 藏品状态（artifacts.status）

| 状态 | 含义 |
| ---- | ---- |
| `registered` | 已登记，尚未分配库位 |
| `stored` | 在库常态保存 |
| `isolated` | 因环境异常或验收不通过被隔离 |
| `frozen` | 借展审批通过，状态被冻结待出库 |
| `out` | 已出库，运输在途 |
| `on_loan` | 展陈中 |
| `returned_pending` | 已归还清点，等待验收复核 |
| `retired` | 已注销（终态，保留审计） |

### 转换表

| 当前状态 | 触发 | 目标状态 | 前置条件 |
| ---- | ---- | ---- | ---- |
| （无） | 登记藏品 | `registered` | 编号唯一 |
| `registered` | 分配库位 | `stored` | 库位存在且启用、保存等级已指定 |
| `stored` | 分配库位 | `stored` | 变更库位 |
| `stored` | 异常隔离 | `isolated` | 同单元存在未关闭异常，隔离动作生效 |
| `isolated` | 处置复核通过 | `stored` | 关联异常关闭 |
| `stored` | 借展审批通过 | `frozen` | 无未关闭异常、前置窗口连续合格、无在途借展 |
| `frozen` | 出库清点+首段交接 | `out` | 清点覆盖全部藏品附件、幂等键唯一 |
| `out` | 展陈确认 | `on_loan` | 展柜前置窗口连续合格、无未关闭异常 |
| `on_loan` | 归还清点 | `returned_pending` | 清点覆盖全部藏品附件 |
| `returned_pending` | 验收通过/带意见通过 | `stored` | 仅由验收复核结果驱动 |
| `returned_pending` | 验收不通过 | `isolated` | 仅由验收复核结果驱动 |
| `registered`/`stored` | 注销 | `retired` | 提供注销理由、无进行中的借展 |

> 禁止项：`frozen`/`out`/`on_loan`/`returned_pending` 状态下的藏品禁止直接修改状态字段；归还后的状态只能由验收复核结果更新；`retired` 为终态。

## 2. 异常事件状态（anomaly_events.status）

| 状态 | 含义 |
| ---- | ---- |
| `open` | 已生成，待处理 |
| `isolating` | 已执行隔离保护 |
| `disposing` | 保护处置进行中 |
| `reviewing` | 处置完成待复核 |
| `closed` | 复核通过，已关闭（终态） |

### 转换表

| 当前状态 | 触发 | 目标状态 | 事务边界 |
| ---- | ---- | ---- | ---- |
| （无） | 巡检发现越界 | `open` | 巡检作业内生成或升级 |
| `open` | 隔离保护 | `isolating` | 与处置记录同事务，单元内藏品同步转 `isolated` |
| `isolating` | 登记处置完成 | `disposing`→`reviewing` | 处置记录创建并提交复核 |
| `disposing` | 处置完成 | `reviewing` | — |
| `reviewing` | 复核通过 | `closed` | 同事务恢复单元内藏品至 `stored` |
| `reviewing` | 复核不通过 | `disposing` | 重新处置 |

### 异常分级（severity）

| 级别 | 判定 |
| ---- | ---- |
| `minor` 轻微 | 连续越界 1–2 次 |
| `major` 严重 | 连续越界 3–4 次 |
| `critical` 危急 | 连续越界 ≥5 次 |

连续越界次数达到启用规则的 `consecutive_breach` 阈值即生成异常；同一单元存在未关闭异常时，后续越界仅升级严重级别，不重复开单。

## 3. 借展申请状态（loan_applications.status）

| 状态 | 含义 |
| ---- | ---- |
| `draft` | 草稿 |
| `submitted` | 已提交待审批 |
| `approved` | 已审批通过（冻结完成），待出库 |
| `in_transit` | 已出库，交接运输中 |
| `exhibiting` | 展陈中 |
| `returned` | 归还清点完成，待验收 |
| `closed` | 验收完成，借展关闭（终态） |
| `rejected` | 审批驳回（终态） |
| `cancelled` | 申请人撤销（终态） |

### 转换表

| 当前状态 | 触发 | 目标状态 | 关键约束 |
| ---- | ---- | ---- | ---- |
| （无） | 创建借展申请 | `draft` | 至少一件藏品 |
| `draft` | 提交 | `submitted` | — |
| `draft`/`submitted` | 撤销 | `cancelled` | — |
| `submitted` | 审批驳回 | `rejected` | — |
| `submitted` | 审批通过 | `approved` | 冻结快照；库房前置窗口连续合格；无未关闭异常 |
| `approved` | 出库清点+首段交接 | `in_transit` | 同事务；清点全覆盖；无未关闭异常；幂等键 |
| `in_transit` | 追加交接/运输节点 | `in_transit` | 时间与序号递增、身份不重复替代 |
| `in_transit` | 展陈确认 | `exhibiting` | 展柜前置窗口连续合格；无未关闭异常 |
| `exhibiting` | 归还清点 | `returned` | 清点全覆盖；幂等键 |
| `returned` | 归还验收 | `closed` | 同事务关闭借展，藏品状态按复核结果更新 |

## 4. 阈值规则版本状态（threshold_rule_versions.status）

| 当前状态 | 触发 | 目标状态 |
| ---- | ---- | ---- |
| （无） | 创建规则版本 | `draft` |
| `draft` | 启用 | `active`（同等级其他启用版本自动退役） |
| `active` | 被新版本取代或手动退役 | `retired` |

## 5. 后台作业状态（jobs.status）

| 当前状态 | 触发 | 目标状态 |
| ---- | ---- | ---- |
| （无） | 入队 | `pending` |
| `pending` | 调度器领取 | `running` |
| `running` | 执行成功 | `done` |
| `running` | 执行失败且可重试 | `pending`（退避后再次领取，attempts+1） |
| `running` | 失败达到最大尝试次数 | `failed`（终态） |
| `running` | 进程重启 | `pending`（启动时恢复，保证可重启恢复） |
