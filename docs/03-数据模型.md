# 数据模型

所有表使用 `INTEGER PRIMARY KEY AUTOINCREMENT` 作为内部主键，天然满足键集分页所需的稳定排序。时间统一为 Unix 秒（`INTEGER`）。可变实体携带 `version` 字段实现乐观锁。

## 1. artifacts 藏品

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 内部主键 |
| code | TEXT UNIQUE | 藏品编号（业务唯一） |
| name | TEXT | 名称 |
| category | TEXT | 类别（古籍/书画/器物…） |
| era | TEXT | 年代 |
| description | TEXT | 描述 |
| status | TEXT | 状态，见状态转换表 |
| level_id | INTEGER FK | 保存等级 |
| storage_unit_id | INTEGER FK NULL | 所在存储单元 |
| note | TEXT | 备注（验收意见等） |
| version | INTEGER | 乐观锁版本 |
| retired | INTEGER | 0/1 是否已注销 |
| retired_reason | TEXT | 注销理由 |
| created_at / updated_at | INTEGER | 创建/更新时间 |

## 2. attachments 附件

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| artifact_id | INTEGER FK | 所属藏品 |
| name | TEXT | 附件名称 |
| spec | TEXT | 规格说明 |
| created_at | INTEGER | 创建时间 |

## 3. storage_units 存储单元

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| code | TEXT UNIQUE | 单元编号 |
| name | TEXT | 名称 |
| kind | TEXT | `warehouse` 库房 / `showcase` 展柜 |
| location | TEXT | 位置 |
| status | TEXT | `active` / `disabled` |
| version | INTEGER | 乐观锁 |
| created_at / updated_at | INTEGER | 时间 |

## 4. preservation_levels 保存等级

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| code | TEXT UNIQUE | 等级编号 |
| name | TEXT | 等级名称 |
| description | TEXT | 说明 |
| created_at | INTEGER | 时间 |

## 5. threshold_rule_versions 阈值规则版本

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| level_id | INTEGER FK | 保存等级 |
| version_no | INTEGER | 版本号（同等级内递增） |
| temp_min / temp_max | REAL | 温度阈值（℃） |
| humidity_min / humidity_max | REAL | 湿度阈值（%RH） |
| consecutive_breach | INTEGER | 连续越界几次触发异常 |
| status | TEXT | `draft` / `active` / `retired` |
| created_at / activated_at | INTEGER | 时间 |

唯一约束：`(level_id, version_no)`；部分唯一索引保证每等级仅一条 `active`。

## 6. sensors 传感器

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| code | TEXT UNIQUE | 传感器编号 |
| storage_unit_id | INTEGER FK | 所属存储单元 |
| kind | TEXT | 类型（温湿度一体等） |
| status | TEXT | `active` / `disabled` |
| created_at | INTEGER | 时间 |

## 7. env_samples 环境采样（只增不改，即环境历史快照）

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| sensor_id | INTEGER FK | 传感器 |
| storage_unit_id | INTEGER FK | 冗余单元，便于窗口查询 |
| temperature | REAL | 温度 |
| humidity | REAL | 湿度 |
| sampled_at | INTEGER | 采样时间（设备时钟） |
| received_at | INTEGER | 接收时间（服务时钟） |
| late | INTEGER | 是否迟到数据（1=仅存档，不参与判定） |
| processed | INTEGER | 巡检是否已处理 |

索引：`(storage_unit_id, sampled_at)`、`(sensor_id, sampled_at)`、`(processed)`。

## 8. anomaly_events 异常事件

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| storage_unit_id | INTEGER FK | 异常单元 |
| rule_version_id | INTEGER FK | 触发所依据的启用规则版本 |
| sample_id | INTEGER FK | 触发采样 |
| severity | TEXT | `minor` / `major` / `critical` |
| status | TEXT | `open` / `isolating` / `disposing` / `reviewing` / `closed` |
| breach_count | INTEGER | 连续越界次数 |
| title | TEXT | 标题 |
| version | INTEGER | 乐观锁 |
| opened_at / closed_at | INTEGER | 时间 |

## 9. protection_actions 保护处置

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| event_id | INTEGER FK | 异常事件 |
| action_type | TEXT | `isolate` / `transfer` / `dehumidify` / `other` |
| operator | TEXT | 操作人 |
| note | TEXT | 说明 |
| status | TEXT | `pending` / `done` / `review_pass` / `review_reject` |
| reviewed_by / reviewed_at | TEXT / INTEGER | 复核人与时间 |
| created_at | INTEGER | 时间 |

## 10. loan_applications 借展申请

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| code | TEXT UNIQUE | 借展单号 |
| borrower | TEXT | 借展方 |
| venue | TEXT | 展出地点 |
| purpose | TEXT | 用途 |
| start_at / end_at | INTEGER | 借展起止 |
| status | TEXT | 见状态转换表 |
| rule_snapshot | TEXT | 审批时冻结的规则快照（JSON） |
| approved_by / approved_at | TEXT / INTEGER | 审批 |
| overdue | INTEGER | 是否逾期（到期作业标记） |
| attention | INTEGER | 是否需要关注（交接超时标记） |
| version | INTEGER | 乐观锁 |
| created_at / updated_at | INTEGER | 时间 |

## 11. loan_items 借展藏品（含冻结快照）

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| loan_id | INTEGER FK | 借展单 |
| artifact_id | INTEGER FK | 藏品 |
| frozen_status | TEXT | 冻结时藏品状态 |
| frozen_level_id | INTEGER | 冻结的保存等级 |
| frozen_unit_id | INTEGER | 冻结时的存储单元 |
| packaging_snapshot | TEXT | 冻结的包装清单（附件 JSON） |
| created_at | INTEGER | 时间 |

唯一约束：`(loan_id, artifact_id)`。

## 12. inventory_checks / inventory_check_items 出入库清点

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| loan_id | INTEGER FK | 借展单 |
| direction | TEXT | `out` 出库 / `in` 归还 |
| idempotency_key | TEXT UNIQUE | 幂等键 |
| operator | TEXT | 清点人 |
| complete | INTEGER | 是否覆盖全部藏品与附件 |
| checked_at / created_at | INTEGER | 时间 |

明细：`id, check_id, artifact_id, attachment_id NULL, present, note`。`attachment_id` 为空表示藏品本体行。

## 13. package_handovers 包装交接

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| loan_id | INTEGER FK | 借展单 |
| seq | INTEGER | 段号（从 1 递增） |
| from_person / to_person | TEXT | 交出方 / 接收方 |
| handed_at | INTEGER | 交接时间（严格递增） |
| location | TEXT | 地点 |
| idempotency_key | TEXT UNIQUE | 幂等键 |
| created_at | INTEGER | 时间 |

## 14. transport_nodes 运输节点

`id, loan_id, seq, node_type(departure/transit/arrival), location, occurred_at, recorded_by, created_at`。

## 15. exhibition_confirms 展陈确认

`id, loan_id, showcase_id, confirmed_by, confirmed_at, note, created_at`。

## 16. return_acceptances 归还验收

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| loan_id | INTEGER FK | 借展单 |
| check_id | INTEGER FK | 归还清点 |
| result | TEXT | `pass` / `pass_with_notes` / `rejected` |
| reviewer | TEXT | 复核人 |
| note | TEXT | 验收意见 |
| reviewed_at / created_at | INTEGER | 时间 |

## 17. artifact_snapshots 藏品状态历史快照

`id, artifact_id, status, level_id, storage_unit_id, note, version, reason, created_at`。藏品每次状态/库位/等级变化均追加一条，永久保留。

## 18. audit_logs 审计日志

`id, actor, action, entity_type, entity_id, detail, created_at`。随业务事务提交或回滚。

## 19. jobs 后台作业

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | INTEGER PK | 主键 |
| kind | TEXT | `patrol` / `loan_due` / `handover_timeout` / 通用 |
| payload | TEXT | 载荷（JSON） |
| status | TEXT | `pending` / `running` / `done` / `failed` |
| attempts / max_attempts | INTEGER | 尝试次数 |
| run_at | INTEGER | 下次可执行时间 |
| last_error | TEXT | 最近错误 |
| created_at / updated_at | INTEGER | 时间 |
